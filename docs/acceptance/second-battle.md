# 索菲亚山脉第二战验收

当前范围是首关福尔斯路线的世界节点1、索菲亚山脉第二战，以及第二战结算后的世界往返和存读。
阶段规格与结果见[接入初章索菲亚山脉第二战与世界往返](https://github.com/mxp-xc/emblem-rekindled/issues/28)。
竖屏是默认与推荐方向，横屏作为可选能力验证。开发自测与用户集中验收分别记录。

## 当前行为

- 首关结算选择福尔斯路线后，选择索菲亚山脉并确认前往；取消不改继续档。
- 世界移动、原入场叙事、第二战标题、对白、目标和福尔斯指挥官设置完成后开放战场。
- 雅木与赛莉卡的培养、装备、耐久、仓库和资金跨关保留；福尔斯在第二战加入。
- 第一轮敌方阶段后出现两组我方援军，第二轮敌方阶段后出现北方敌军；第九轮敌方阶段切换原五名敌军的追击策略。
- 击败塞格获胜，雅木或福尔斯死亡失败；胜利按原版优先判定。结算恢复正式队伍，奖励1000金币且只发一次。
- 鲁卡与希尔克分别通向节点2与8。已访问节点可往返，不重打旧战；商店按队伍驻留地点取商品。
- 继续档标明实际关卡，命名世界档与继续档隔离。旧首关记录仍可读取；已读升级教学跨关保留。
- 尚未接入的关卡明确提示制作中，不改变当前进度。
